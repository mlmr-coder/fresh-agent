# 能力中心

“能力中心”是鲜小助面向用户的统一能力入口，页面分为“专家”“技能”“连接器”三个标签。

每个会话的专家选择保存在用户数据目录 `~/.pinvou3/sessions/<会话 ID>/persona.json`，与应用安装目录分离。启动或打开历史会话时恢复绑定，并在恢复后的第一轮重新注入专家正文，随后仍使用轻量人设提醒；仅恢复挂件不能替代运行时恢复。旧会话尚无绑定文件时，按 `persona_events.json` 最后一次添加/卸下事件迁移专家 ID，正文始终从专家库读取。主动移除保存显式空值，避免旧时间线把专家重新带回；写入失败保留原选择并提示。会话删除时绑定随其私有目录清理。

- 专家：定义角色、专业背景、表达方式和工作偏好，由专家卡数据提供。
- 技能：只包含可独立使用的 `SKILL.md` 工作流程。
- 连接器：包含 MCP、外部 API、CLI 或授权流程；同时携带技能的组合包也只显示为一张连接器卡。

新增或合并上游能力时，应把后端市场条目放入已有的事实源：连接器进入 `list_marketplace_tools`，纯技能进入 `list_marketplace_skills`，专家进入专家卡数据。`companion_skills` 表示技能由连接器认领，界面会自动将组合包放到“连接器”并隐藏重复的技能卡。不要按名称、品牌或前端展示文案手工分组。

技能和连接器列表中的“按类型”读取技术形态标记，形成插件包、MCP、Skill、CLI、API 等分组；“按业务”读取条目的 `category` 元数据，形成沟通协作、文档知识、研发、金融、生活和其他等分组。这两个开关只改变浏览方式，不改变能力归属、安装状态或实际执行行为。

连接、安装、断开、卸载或更新完成后，详情页从刷新后的列表条目重新派生当前卡片。卡片、详情状态提示和顶部动作按钮必须使用同一份 `bundle_readiness`/市场状态，不能在详情弹窗中保留独立的连接状态。

聊天输入框按照“添加、工作模式、专家、连接器、知识库”的顺序展示，模型选择器位于右侧操作区。专家是单选能力，悬停后可从头像右上角取消。连接器显示最多三个已开启且授权状态可用的头像，超出使用 `+N` 表示；未完成授权的条目不会计入头像。连接器来源统一为 `BundleRegistry`：包含 MCP、CLI、组合包和带凭据的技能包（如 ima），通过 `bundle_readiness` 与 OAuth 状态判断可用性。点击头像组仍可逐项开关或进入能力中心添加。头像不代表会话级授权，开关仍沿用下文的模式级语义。

技能不在底部显示头像。在输入框任意位置键入 `/` 可按中文展示名称、内部名称、别名或描述选择已启用的技能；选择后在正文中显示“技能小图标＋中文名称”的浅灰标签，可连续添加多个，并在前后输入、整项删除、撤销；继续输入任务后发送。输入框用可编辑文本和不可拆分的标签呈现，草稿与发送仍保留纯文本 `/技能名` 引用，不向底座发送 HTML。技能列表来自 `list_composer_skills`：复用该模式的 `enabled_skills_for` 与 CodeWhale `SkillRegistry`，仅展示独立技能；使用 `BundleRegistry` 的包归属排除 CLI、MCP 组合包和凭据型连接器的配套技能。此筛选只影响选择列表，底座仍可按已启用连接器加载配套技能。底座已有的提示约定负责通过 `load_skill` 加载被用户点名的技能；选择技能不会增加工具权限，也不会更改全局开关。这里没有另建技能执行器，也不拦截或承诺模型一定按某条工作流程执行。

`@` 列出当前会话的文件和附件，插入带完整路径的文件引用，避免同名文件混淆；选中建议不会自动发送。建议列表支持方向键、Enter/Tab 选择、Esc 关闭；输入法确认和 Shift+Enter 保持原行为。

从旧底栏技能开关升级时，启动迁移会一次性清理普通聊天中“已安装的独立技能”的遗留停用记录，解决技能中心显示已安装、`/` 却不可选的问题。迁移按包形态与归属判断，保留连接器、凭据型技能包、未安装包、隐藏设置及代码模式权限；完成标记保存在本机 `disabled_bundles.json`，后续启动不重复重置。选择列表与引擎继续共用迁移后的启用集，不能仅在前端补出不可执行的技能。安装、开关变化和窗口重新获得焦点会刷新技能建议。

后续合并上游新增技能时，保持实际 `SKILL.md`、别名和包归属元数据即可自动进入 `/` 列表，不要在前端硬编码技能名称；新增连接器继续登记能力包与对应就绪状态，不再维护一份输入框专用的 CLI 名单。普通聊天列宽统一为 850px，消息与输入框对齐；桌面侧栏默认展开，紧凑 Web 视口保持抽屉默认关闭。

输入框连接器菜单中的绿色开关、已连接标记、头像和数量统一由“连接就绪且未禁用”派生。就绪但禁用的连接器显示“已关闭”；未就绪的条目显示“待连接”和“去连接”入口，不显示绿色开关，也不计入头像。连接状态变化不改写用户保存的开关偏好。重新打开菜单、窗口获得焦点或收到能力变更事件时，统一刷新连接状态、模式开关与可见性；保存开关期间丢弃旧查询结果，刷新失败保留上次状态并提示。

连接器和技能开关按会话模式（普通聊天/代码）持久化，并约束该模式下的所有会话。当前轮次处理中会锁定开关；生成结束后可调整，工具禁用、技能目录和命令权限从下一轮起同步生效。

输入框默认保留 88px 的编辑高度，随内容增长至 200px 后内部滚动。上下文用量以模型名称前的小圆环表示，悬停、键盘聚焦或轻触可查看使用量、上限和百分比；接近上限时使用橙色/红色提示。正文与过程分层显示：思考和工具摘要使用紧凑灰色行，执行中的输出继续可见，完成后默认收起，失败和待确认信息保持可见。
